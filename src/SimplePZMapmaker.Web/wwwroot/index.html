Import will replace the current map. We take streets, water, forests and building outlines from OpenStreetMap; We create the rooms ourselves.

Overloaded OSM servers are retried through backup servers. OSM coverage varies; unsuitable buildings are skipped. Native game terrain remains flat. Source: OpenStreetMap contributors / ODbL.
GAME MAP

Build mod

The editor will create a ZIP with the Build 42 map, spawn points, rooms, zombie density and original project.

  1. Unzip the mod folder from ZIP to Zomboid\mods.
  2. Enable the mod in Project Zomboid.
  3. Create a new game and select the created map.

Check on a separate new save. The map has not been verified by a game walkthrough; The editor does not change existing worlds. Several mods on the same coordinates may conflict.

From editor to game

  1. Create a base or import a district from OSM.
  2. Draw the ground and roads, place the buildings. Buildings cannot cross cell boundaries.
  3. Place a spawn point on land outside the building. Select the zombie density and draw it with the Zombie tool.
  4. Save the project for further editing.
  5. “Build mod” → “Download ZIP”. Extract the mod folder into Zomboid\mods, enable the mod, create a new game.

The 3D overview shows map shapes rather than exact game sprites. Native terrain remains flat. Edit multi-story buildings in the workshop. GeoJSON imports require WGS84 coordinates and OSM properties: highway, building, natural, landuse, or waterway.
