# SimplePZMapmaker

Локальный редактор карт для **Project Zomboid Build 42**. C#/.NET 10, интерфейс в браузере; для создания карты программирование не требуется.

## Запуск

1. Запустите `Start.cmd` из корня проекта.
2. Откроется `http://127.0.0.1:48765`.
3. Приложение требует установленный **.NET 10 ASP.NET Core Runtime**. Для пересборки нужен .NET 10 SDK; на текущем компьютере он установлен.

Собранное приложение: `artifacts/app/SimplePZMapmaker.Web.exe`. `Start.cmd` запускает сервер в фоне. Для остановки завершите только процесс `SimplePZMapmaker.Web.exe` в диспетчере задач. Логи — `work/logs/`. Сервер слушает только loopback.

## Создать карту

- «Новая карта»: пустая земля, небольшой город либо лес с рекой. Размер 256–1024, воспроизводимый seed, плотность леса и зданий.
- Кисть B, прямоугольник A, дорога R. Выберите поверхность и размер кисти слева. Для дороги протяните линию; размер кисти задаёт её ширину.
- Здание H: дом с тремя комнатами, магазин или склад. Поставьте на суше; здание не должно пересекать другое здание или границу ячейки 256×256. Через «Выбор» V можно изменить его размер/положение или удалить.
- Точка появления P: поставьте снаружи здания на суше. Выберите точку инструментом V и нажмите Delete для удаления; минимум одна должна остаться.
- Зомби Z: нарисуйте плотность выбранным значением от 0 до 255. Разрешение слоя — один чанк 8×8.
- Ctrl+Z / Ctrl+Shift+Z — отмена/повтор; колесо — масштаб; средняя кнопка, правая кнопка или Space — перемещение.
- «Обзор 3D» — схематическая изометрия. Редактирование выполняется в виде сверху. Игровые спрайты в редакторе не воспроизводятся.

## Реальный район

«Импорт реального места» → найдите город/адрес, выберите результат → задайте ширину участка и размер игровой карты → «Показать участок» → «Импортировать участок».

География заменяет текущую карту. Перед заменой сохраните проект. Дороги и полигоны масштабируются с сохранением географических пропорций; здания упрощаются до прямоугольников и получают сгенерированные интерьеры. Пересекающиеся, слишком большие и неподходящие здания пропускаются с отчётом. Полнота зависит от исходных данных.

«Загрузить GeoJSON»: FeatureCollection с LineString, Polygon, MultiLineString или MultiPolygon; WGS84 `[долгота, широта]`; свойства `highway`, `building`, `natural`, `landuse`, `waterway`, `shop`, `name`. Поддерживается также JSON Overpass. До 16 МБ / 250 000 точек / 30 000 объектов. Сеть для импорта файла не нужна. Для автоматического определения участка нужен небольшой географический охват.

Google Maps не используется как источник экспортируемой геометрии. Перепады высот SRTM и многоэтажные здания пока не реализованы.

## Сохранить и экспортировать

«Сохранить» скачивает `.pzmap.json`; «Открыть» продолжает работу с ним. Автосохранение остаётся в локальном хранилище браузера, привязанном к адресу редактора. Очищение данных браузера удалит его; сохраняйте отдельный файл проекта.

«Собрать мод» → «Скачать ZIP». Внутри находится папка `SimplePZMap_<идентификатор>` с:
- `42/mod.info`, `common/`, `42/media/maps/<идентификатор>/`;
- native B42 `.lotheader`, `.lotpack`, `chunkdata_*.bin`;
- room/building definitions, `spawnpoints.lua`, `objects.lua`, `worldmap.xml`;
- `project.pzmap.json`, `ATTRIBUTION.txt`, `INSTALL.txt`.

Распакуйте папку мода в обычную папку `Zomboid/mods`, включите его и создайте **новую игру**. Название и seed определяют ID мода; изменение одного из них создаёт другой ID. Координаты начала по умолчанию — ячейка 100,100. Несколько карт на одинаковых координатах могут конфликтовать. Приложение не копирует файлы в игру и не изменяет сохранения автоматически.

**Игровое прохождение экспортов пока не проверено.** Структурные тесты файлов не заменяют запуск новой карты в игре. B41 не поддерживается. Конкретные результаты проверок — `docs/STATUS.md`.

## Разработка

Все команды выполняйте из корня после `. ./scripts/WorkspaceEnv.ps1`: скрипт направляет временные файлы, кэши .NET/NuGet/npm/Chromium в `work/` на том же диске.

```powershell
. ./scripts/WorkspaceEnv.ps1
dotnet run --project src/SimplePZMapmaker.Web
./scripts/verify.ps1
./scripts/publish.ps1
```

Основные тесты не требуют NuGet-пакетов. Браузерные проверки требуют Playwright только в `work/qa/`:

```powershell
. ./scripts/WorkspaceEnv.ps1
npm install --prefix work/qa --no-audit --no-fund --ignore-scripts playwright
node work/qa/node_modules/playwright/cli.js install chromium --only-shell
# При запущенном сервере:
node scripts/verify-browser.mjs
```

Регрессионные тесты записывают скачанные проекты, ZIP и снимки только в `work/qa-results/`. Исходники на ветке `develop`; внешних публикаций нет. Лицензия GPL-2.0-or-later, происхождение форматов и данных — `docs/PROVENANCE.md`.
