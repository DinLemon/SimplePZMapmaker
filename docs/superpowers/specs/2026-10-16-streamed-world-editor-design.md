# Streamed world editor design

Implement the editor developer's agreed share of the Pilna collaboration. Accurate geography remains primary; original WGS84 evidence, IDs, manual edits, providers and dependencies are preserved. The companion developer owns rotation/fence/small-building core and CLI; this change publishes the integration contract without silently implementing an incompatible duplicate.

Deliver: true revision-pinned section workspace loading/saving/export without whole-world raster allocation or the aggregate 128 MB workspace ceiling; explicit bounded per-section/metadata budgets and atomic recovery; browser section navigation with manifest-only neighbours, unsaved-edit protection, minimal shared context, seams and reliable history; polygon game/vehicle zones, reversible zombie density regions and reviewed existing-room naming rules; layer controls and concrete interactive adapters to core capabilities; English documentation and actual browser/native verification.

Reuse current .NET 10/ES modules, section archives, jobs, native tile composition and existing gameplay catalogs. Preserve all old maps. Extend optional fields rather than inventing native zone formats. Polygon export uses deterministic rectangle spans. Density edits retain an original baseline and report 8-tile quantization. Native gates and small structures are enabled only by an implemented advertised core capability; UI must explain external integration dependencies.

Visual direction follows the current muted green map workbench: base #172623, surface #233b32, text #e7dfc9, selected #edc57e, source #6bc8e3, warning #ed987b. Use existing system typography and compact labelled controls, one clear active-section overview, line handles and explicit loaded/unloaded states. Layer state is editor view state; hiding a layer never deletes objects or changes exported geometry.

Acceptance: focused RED/GREEN tests plus whole suites; disjoint section reads and saves never load unrelated corrupt rasters; stale revisions/cancelled writes preserve previous manifests; streamed export preserves shared crossing objects and source records; polygons do not fill holes/concavities or falsely block roads; density removal preserves later manual edits; browser undo/reload and section switch exercise real APIs. A synthetic 13-section Pilna-shaped fixture is available for integration; actual private scenes are used only if present, never claimed if unavailable. No interactive game session is started.
