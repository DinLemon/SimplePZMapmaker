# Transfer lessons: integrated implementation and acceptance

The supplied `TRANSFER-LESSONS.md` is requirements/evidence input. Its source survey and Build 42 pitfalls are reflected in the implementation, with external availability and client acceptance kept distinct from tested behavior.

## Integrated behavior

- Supplemental source preparation and baseline composition are in the existing **Real places & sites** window. Cadastral parcel tags, explicit WGS84/Mercator conversion, stable identities, full external attributes, concise project/export attribution, per-field inference and local source corrections are supported. NSPD sampling has preflight budgets, actual progress and resumable point caching. See [CADASTRAL-SOURCES.md](CADASTRAL-SOURCES.md).
- **Generation Studio → Surveyed parcels · rural yards** retains main houses and fills local complete parcels with access paths, a separate front garden, native FenceLines/wicket and an open vehicle entrance, shed/bath/toilet/greenhouse and rear garden. Stable children and terrain baselines make repeat completion idempotent and regeneration preserve edits. Shared ParcelPlacement protects full object footprints and passages. Crossing/locked/roadless/oversized parcels remain explicit skips, not fabricated ownership. Source-overlay visibility no longer blocks generated-object bookkeeping; editing actual source boundaries still requires the source layer.
- The `ru-rural` surface profile is opt-in for standalone maps, World import and CLI scenes, retained in the world reference. Actual `surface` tags always win. Source tags are retained, and inferred road decisions are reported.
- The **Emergency shelter** street ensemble creates four facilities, a tent camp, connected walkways and native fences. Preview/apply/stale checks and resource validation are shared with existing ensembles. It is an authored scenario, not evidence of an observed PVR.
- Rural wall/roof/trim selection uses active native resources and ownership. `scripts/make-rural-assets.py` creates 42 original transparent native frames, a property spec and explicit green/maroon board/fence/attachment bindings. Build/preview/attach through Agent assets produces a separate native mod; it is not installed in a real Zomboid profile. The acceptance archive is `work/rural-original/rural_original.zip`. A matching three-panel artwork/state set is included, but linked interactive three-panel gate behavior is not claimed: the default vehicle entrance is an open gap.
- A single invertible world mesh supports protected block rotation and field compression. Roads, polygons/holes, buildings and fences share it before section offsets. Fetched geometry outside its bounded domain is clipped before mapping; source WGS84 remains separate. Browsing, elevation sampling and reference bindings use the matching inverse and handle padding without inventing geographic positions. Affine worlds remain compatible. Map format 15 supports independent original/projected topology and parcel-generation state; world format 10 carries the common deformation/regional profile. See [GEOGRAPHIC-DEFORMATION.md](GEOGRAPHIC-DEFORMATION.md).
- Gabled/shed roofs on L/T/courtyard footprints use deterministic rectangular wings in native composition. Roofs never fill courtyard holes; wings under two tiles use their flat weather cover. This is automatic decomposition, not a new independent authored RoofParts format or a claim of seamless custom valley artwork.
- Editor zombie density stays 0–255; native lotheader output uses the documented 0–10 policy. Single-map, loaded-world and streamed-world archives include the notice; the export panel and Project Doctor expose it. TBX/TMX object bounds are checked before indexing. Supported native FlatTop roofs round-trip; unsupported slopes/partial roofs/west overlay mirroring produce explicit strict errors/lossy reports. Existing tile-definition collision, owner/dependency and interior-spawn checks remain active. See [TRANSFER-B42-VALIDATION.md](TRANSFER-B42-VALIDATION.md).

- Real installed B42 catalog validation covers the generated block, PVR resources and the original native asset pack. Runtime checking caught and corrected the wrong use of floor flower tiles and missing chopping-block collision flags.
- Fresh Chrome executes actual preview/apply/Undo (4 → 20 → 4 buildings), source normalization/composition/download and shared-frame preview against the Release API, with no page errors. Warning lists are expandable instead of pushing inspection controls far down the window.

Run `scripts/verify-transfer-lessons-live.mjs` and `scripts/verify-transfer-warp-import.mjs` against a separate local Release (default port 48778). The C# suite registers the B42, cadastral, mesh, regional and parcel integration tests; JS covers stream boundaries/cancellation, independent topology, layout/inverse and layer guards. The procedural-pack test uses `PZMAP_RURAL_RECIPE_DIR` and the installed `PZMAP_GAME_PATH`.

## Explicit limits

The live NSPD point request timed out; provider availability is not certified. Google/Yandex scraping and automatic listing-image ingestion are not adapters. Partial parcel completion across section boundaries is reported rather than silently split. Three-wide linked interactive gate logic, arbitrary BuildingEd slope/overlay interoperability and visual matching/weather/population responsiveness still need their own game/editor client acceptance. Do not infer those results from a green build or headless probe. No commit, push, PR, GitHub release or modification of the real Zomboid profile is part of this change.

## Review regression coverage

Independent review reproduced destructive aliasing when copying/creating a site, loss of completion during preserving source refresh, ignored building/site protections, an original-ring indexing error after line clipping and canonical source identity drift. Site operations now detach new/copy/moved generator state, update preserves authoritative ownership, regeneration respects pins/protected/locked cells and explicit membership, and a completed parcel refresh retains its members/ground/ownership together. Split paths retain their original ring index. Source normalization/composition/import and CLI scenes share explicit canonical source identities. `TransferOwnershipRegressionTests` and `SourceIdentityRegressionTests` reproduce these failures; the source editor also uses the single Map layers visibility state and renders source boundaries once.

Final review probes cover seven ownership/protection/fragment regressions and thirteen canonical-identity regressions. An independent recheck reports no remaining findings within those seven original review findings; this is not a repository-wide security claim. The UI source editor now shares the global source-layer visibility and the live browser test includes an actual reviewed site rename.
