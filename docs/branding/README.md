# Project branding

The folded-map logo is original AI-assisted artwork created for SimplePZMapmaker. Its connected sections, road and home describe the editor without reproducing game sprites or an existing game logo.

The animated workflow is an original procedural illustration, not an editor recording. `scripts/render-branding.py` generates its GIF and static poster. It shows area selection, terrain, buildings and sequential section export. Game and third-party map imagery are not included.

These project assets follow the repository license. The logo PNG retains a transparent background; the GIF has a fixed dark background for consistent rendering on GitHub.
