# Сшитый мир

Новый пример0.7: `World-DEM.pzworld.json` / `World-DEM-B42.zip`. Два соседних участка, один общий дом с погребом, соединённые авторские дорога/река и нативный контейнер с моделью Toolbox. Реальный DEM района Смоленска загружен из Terrain Tiles:256×256 отсчётов,161…269м. Источник/лицензия/геопривязка — в `World-DEM-source.json`; время импорта не означает дату измерения. Планировка авторская, не OSM-реконструкция. Высоты отображаются слоем и входят в elevation.asc; игровая земля остаётся плоской. Общие комнаты корректно разделены между двумя нативными ячейками; игровые классы читают13rooms/4basementrooms/3basementstairtiles. Потребуется редактор0.7 или новее для мира2 и карт7.

Откройте `world.pzworld.json` через **«Мир и участки» → «Открыть мир»**. Двенадцать соседних участков содержат готовые здания, лес, дорогу и декор; общий охват3072×1024. Дополнительный участок512×512 показывает дом через границу нативной ячейки256×256. Всего13 участков и16 ячеек.

В подвале первого дома размещена модель `Base.BeerBottle` с масштабом0,5. Её оригинальные геометрия и текстура берутся из игры; ZIP содержит только ссылки и собственный код размещения статичного предмета.

`Worlds-B42.zip` — единый нативный мод этой территории. Координаты100,100 пересекаются с другими примерами: запускайте отдельно в новом мире либо переместите участки и пересоберите. Игра и её ресурсы в пример не включены.

Повторная сборка с установленной игрой: `. ./scripts/WorkspaceEnv.ps1`, затем `dotnet run --project tools/WorldExample`.

`Smolensk-small.pzworld.json` и `Smolensk-small-B42.zip` — небольшой реальный участок центра Смоленска:54,778–54,780° N,32,045–32,048° E, примерно223×193м. Данные Overpass API получены13 октября2026; исходная дата2026-10-13T07:54:29Z. Общий масштаб1м/клетка, участок512×512 с padding,4 нативные ячейки и8 зданий. Это проверка импорта выбранного участка, не всего города. Координаты130,130. Атрибуция OSM/ODbL включена в исходник и ZIP.
