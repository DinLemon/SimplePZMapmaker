# Automatic furniture

Generated interiors choose furniture by room purpose. Bedrooms and guest rooms receive beds and dressers; kitchens, including imported restaurant/bakery kitchens, prioritize a stove, sink and fridge before counters. Repeated counters in a room prefer one matching catalogue variant. Public bathrooms omit domestic baths. Offices, classrooms, shops and storage areas use the existing generic vanilla groups, with bounded rows of seats or shelves in larger rooms. Halls, stairwells and balconies remain clear. This is procedural furnishing with the supported catalogue, not reconstruction of an observed real interior.

Each placement checks the complete object footprint, authored partitions, doors, windows, stairs, existing tile groups and model footprints. Its usable front stays clear, and removing its occupied squares may not disconnect the room's remaining walkable space. Essential items try alternate fitting variants before giving up. A small or obstructed room can omit an item instead of blocking access. Automatic multi-floor layouts reserve a stair bypass within their existing footprint; imported courtyard holes and exterior shape remain intact.

Import room tags are applied to furniture too: newly generated rooms renamed to a kitchen or shop no longer keep their earlier bedroom/house contents. A repeated unchanged room assignment does not reroll objects. Manually modified buildings are not automatically refurnished by this tagging step. Existing saved projects remain readable and are not silently rewritten.

In **Building workshop → Automatic furniture → Refurnish this floor**, review a new arrangement without regenerating the plan. It replaces ordinary furniture objects on the selected floor, retaining walls, floors, stairs, individually placed tile groups and 3D models. It is one draft undo step; apply the building to commit it to the map, or Undo/Cancel to retain the prior version. Ordinary manually placed primitive beds/seats/counters also belong to the replaced furniture layer; use complete tile groups for placements that must remain protected.

This command does not repair arbitrary manually authored walls or stair layouts. Use the floor/stair tools and access diagnostics for those; generated stair circulation is corrected on newly generated/imported layouts. Existing custom sprites and room-specific assets can still be placed manually.
