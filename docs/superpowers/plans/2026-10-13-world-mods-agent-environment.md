Export references required mods and generates only original placement glue.

Browser project synchronization uses revisions and undoable changes to prevent silently overwriting newer manual edits; no shell or arbitrary external file commands.

- Environment workshop: visible sprite/model brushes, selection/move/rotate supported variants/delete, terrain/surfaces, roads/paths, vegetation and object groups/regions, signed levels where supported; history and native previews/export must agree.
- More original editable building templates and themed environment arrangements using validated game references, with dependency/source metadata preserved.
