# Смоленск — центр, 1,5 км

Откройте `smolensk.pzmap.json` через «Открыть проект». Это участок 1500×1500 м вокруг 54.7789701,32.0471812, карта 1024×1024; не весь город. Исходные контуры дорог, воды, растительности и зданий получены из региональной выгрузки OSM France; дата снимка 2026-10-11T00:29:05.0000000+00:00.

Размещено 352 зданий из 772 исходных контуров. Ограничения размеров, пересечений и расположения отражены в `import-report.json`; помещения и неподтверждённая этажность создаются генератором. `recipe.json` и нормализованная `osm-source.json` позволяют повторить импорт без сети через GeoJSON/OSM JSON. Полный региональный PBF не распространяется.

`Smolensk-B42.zip` — native-мод Build42. Следуйте INSTALL.txt внутри архива. Включайте отдельно от остальных примеров: они занимают те же мировые координаты.
