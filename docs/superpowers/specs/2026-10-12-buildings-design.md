# Building workshop 0.3

User approved every proposal: multistorey buildings, arbitrary floor footprints/annexes/courtyards/balconies, manual floor/room/wall/opening/stair editor, material/roof variants, archetype-aware procedural layouts, OSM levels/roof metadata, regenerate Pilna without losing manual changes, and real-game verification where available. Keep source, scratch and caches in the project workspace. Continue publishing source and a reviewable release to the already-authorized private GitHub repository.

Project format2 prevents older editors silently dropping new floors/library. Reader accepts legacy version1, whose buildings without a design retain the original export. Design contains1–16 living floors, each as a bounded cell string (dot=void; room code=occupied), named room codes, explicit wall/door/window/open overrides and furniture/stairs. Shared material, roof and variant; per-building source identity, source kind and provenance of inferred levels. Grid64x64 remains maximum footprint; existing256-cell boundaries remain. Independent floor footprints support terraces/annexes. Union occupancy (including perimeter walls), not rectangle bounds, governs new-design collision/water/spawn checks. Bounds remain conservative for cell crossing.

Core generates valid connected floor layouts and stair runs with landings. Export native room z/rectangle decomposition and dynamic level range; holes above stairs; correct installed stair sprites. Roof/facade materials use verified tile identifiers. Validation bounds all counts, dimensions, enum values and disconnected/unreachable floors. UI operates a cloned draft, previews each floor over a ghost lower floor, supports local undo/redo and explicit apply/cancel. Failed/cancelled edits never mutate the map. Outer map history records one applied building edit. New shape/room/edge/object tools keep an accessible textual validation result and inspector controls.

Generator archetypes: house, apartments, school, shop, warehouse/industrial, clinic, hotel and garage. Deterministic variation in layouts/materials/roofs; single/all regenerate retain positions/source attribution and skip manually modified buildings unless explicit single-building replacement is chosen. OSM levels/height/roof consumed with source-derived vs inferred labels and limits reported. Reimport supports retaining edited buildings by source identity and newly placed manual buildings. Fixed Pilna source remains reproducible offline. Native gameplay correctness must be tested against installed game separately from structural checks; report any runtime block honestly.
