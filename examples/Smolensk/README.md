# Central Smolensk — 1.5 km

Open `smolensk.pzmap.json` with **Open**. It covers 1500×1500 m around 54.7789701,32.0471812 on a 1024×1024 map, not the entire city. Road, water, vegetation and building outlines came from the OSM France regional extract with snapshot 2026-10-11T00:29:05.0000000+00:00.

The saved example places 352 buildings from 772 source outlines. Size, overlap and location limits are recorded in `import-report.json`; interiors and unconfirmed level counts are generated. `recipe.json` and normalized `osm-source.json` allow offline reproduction through GeoJSON/OSM JSON import. The full regional PBF is not distributed.

`Smolensk-B42.zip` is a native Build 42 mod; follow its `INSTALL.txt`. Enable it separately from other examples occupying the same world coordinates. Geography: © OpenStreetMap contributors / ODbL 1.0; see `ATTRIBUTION.txt`. Game textures are not bundled. Character traversal and game lighting are not verified.
