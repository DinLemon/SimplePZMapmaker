# SimplePZMapmaker Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. User carte blanche authorizes routine implementation decisions and execution without an additional review gate.

**Goal:** Deliver a locally runnable editor that creates, edits, imports and exports PZ maps.
**Architecture:** .NET core + local ASP.NET host + JavaScript canvas modules. The core is independently tested; exports are downloadable archives.
**Tech Stack:** .NET 10, C#, plain HTML/CSS/JavaScript, node:test.
**Spec:** docs/superpowers/specs/2026-10-12-mapmaker-design.md

## Global Constraints
- Loopback only; fixed upstream OSM service; no user game/save mutations.
- Native B42: cells 256, chunks 8; maps 256/512/768/1024 squares.
- Russian user interface, portable project format, OSM attribution preserved.
- No game tile artwork redistribution. GPL-2.0-or-later for export code derived from GPL mapping-tool algorithms; disclose provenance.

## Review Focus
- Imported geometry partly outside the map is clipped and never loops over unbounded coordinates.
- Corrupt saved projects and missing arrays return understandable errors.
- Export retains map edits, room definitions and safe spawns at nonzero world offsets.
- Build 42 format is not confused with B41 geometry.
- Browser edits and recovery remain consistent across regeneration/import and undo.
