РЕАЛЬНАЯ ГЕОГРАФИЯ

Принести место на карту

Импорт заменит текущую карту. Улицы, вода, леса и контуры зданий берём из OpenStreetMap; комнаты создаём сами.

Данные OSM различаются по полноте. Неподходящие здания будут пропущены. Рельеф с перепадами высот не переносится. Источник: OpenStreetMap contributors / ODbL.
КАРТА ДЛЯ ИГРЫ

Собрать мод

Редактор создаст ZIP с картой Build 42, точками появления, комнатами, плотностью зомби и исходным проектом.

  1. Распакуйте папку мода из ZIP в Zomboid\mods.
  2. Включите мод в Project Zomboid.
  3. Создайте новую игру и выберите созданную карту.

Проверяйте на отдельном новом сохранении. Карта не проверена игровым прохождением; существующие миры редактор не изменяет. Несколько модов на одних координатах могут конфликтовать.

От редактора до игры

  1. Создайте основу или импортируйте район из OSM.
  2. Дорисуйте землю и дороги, поставьте здания. Здания не могут пересекать границы ячеек.
  3. Поставьте точку появления на суше снаружи здания. Выберите плотность зомби и нарисуйте её инструментом «Зомби».
  4. Сохраните проект для дальнейшего редактирования.
  5. «Собрать мод» → «Скачать ZIP». Распакуйте папку мода в Zomboid\mods, включите мод, создайте новую игру.

Обзор 3D показывает форму карты, а не точные игровые спрайты. Настоящий перепад высот и многоэтажные здания пока не поддерживаются. Для импорта GeoJSON нужны географические координаты WGS84 и свойства OSM: highway, building, natural, landuse или waterway.
