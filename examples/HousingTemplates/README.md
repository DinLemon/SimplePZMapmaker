# Шесть жилых шаблонов

Оригинальные адаптации деревенских, поселковых и городских домов по [архитектурным источникам](../../docs/HOUSING-REFERENCES.md).

- `village-izba.pzbuilding.json`: деревянная изба, 16×14, один этаж, сени, крыльцо и погреб.
- `village-veranda.pzbuilding.json`: дом с боковой деревянной верандой, 20×16, один этаж.
- `settlement-two-storey.pzbuilding.json`: кирпичный поселковый дом, 30×24, два этажа, восемь квартир.
- `urban-brick-five.pzbuilding.json`: кирпичный корпус, 48×26, пять этажей, два независимых подъезда, 40 квартир.
- `urban-panel-five.pzbuilding.json`: серый панельный корпус с другой планировкой, 48×24, пять этажей, два независимых подъезда, 40 квартир.
- `urban-panel-nine.pzbuilding.json`: панельная башня, 32×30, девять этажей, четыре квартиры на этаж. Функционального лифта нет.

Для отдельного дома использовать «Загрузить шаблон JSON» (формат шаблона3). `catalog.json` содержит описание и ссылки каждого шаблона. Для готовой площадки открыть `housing-templates.pzmap.json` (формат проекта5). `HousingTemplates-B42.zip` — нативный Build42-экспорт всех шести зданий; инструкция установки внутри архива.

Общий пример: одна ячейка 256×256, world origin **100,100**, spawn (12,12). Включать отдельно от других примеров с теми же координатами или изменить world origin и экспортировать заново. Архив содержит идентификаторы vanilla-тайлов, не игровые картинки. Структура native chunks, этажи, лестничные отверстия и наличие всех98 используемых тайлов проверены; полное прохождение персонажем отдельно не подтверждено.
