# Пильна

Воспроизводимый пример импорта реального посёлка из OpenStreetMap.

- `osm-source.json`: полученный ответ Overpass,2378 объектов,1789 контуров зданий и 439 дорожных объектов.
- `recipe.json`: точные границы, seed, размер 2048 и положение в игровом мире.
- `pilna.pzmap.json`: редактируемый проект для кнопки «Открыть»; также доступен в редакторе через «Открыть Пильну».
- `Pilna-B42.zip`: мод с картой для Build42; установка описана внутри.
- `import-report.json`: сколько объектов размещено и почему остальные пропущены.
- `ATTRIBUTION.txt`: источник географии и условия ODbL.

Ширина/высота охвата около 3,7/4,7 км; масштаб 2,29 м на клетку. Север расположен сверху. География упрощена под квадратную сетку. Контуры зданий превращены в прямоугольники, интерьеры создаются программой. Это игровой вариант посёлка, а не точная реконструкция домов.

Первый импорт 1024 оставлял 243 здания из 1789. Версия 2048 с шириной дорог в метрах оставляет 1439. Пропущено 350:131 контур на воде/дороге,103 пересекают границы ячеек,115 пересекаются с уже размещёнными прямоугольниками,1 слишком большой. Ничего из этого не скрыто в отчёте.

Повторить при запущенном редакторе из корня репозитория:

```powershell
. ./scripts/WorkspaceEnv.ps1
node scripts/build-pilna.mjs
```

Скрипт использует зафиксированный исходный файл; сеть для повторной генерации не нужна. Для свежих данных используйте поиск Пильны в UI и «Весь найденный посёлок или район».

Структурное чтение всех 64 ячеек экспорта, проверки редактора и повторное открытие проекта выполняются автоматически. Прохождение карты в Project Zomboid пока не проверено; железнодорожный слой и точные фасады ещё не реализованы.
