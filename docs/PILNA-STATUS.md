# Пильна — проверка 0.2, 2026-10-12

Получены реальные данные Overpass: 2378 объектов, 1789 зданий, 439 дорожных объектов. Также отдельно получен исходный XML через OpenStreetMap API для диагностики; он остаётся только в git-ignored work/, приложение использует зафиксированный JSON.

Повторная загрузка через основной `/api/import/osm` позднее вернула 504. Это не отменяет успешное получение исходных данных, но не является успешным повторным сетевым импортом. Зафиксированный пример и повторение через исходный файл не зависят от доступности сервисов.

При размерах 1024 — 243 здания; при 2048 с дорожными ширинами в метрах — 1439. Пропущено 350: 131 вода/дорога, 103 граница ячейки, 115 пересечение прямоугольников, 1 слишком большой контур. Охват примерно 3,7×4,7 км, масштаб 2,28995 м/клетка. Комнаты и мебель созданы генератором.

Независимый читатель ZIP/LOT проверил все 64 ячейки и 65 536 чанков, 4281 комнаты, 1439 зданий и 20 имён тайлов. Все 20 присутствуют в установленной игре. Повторно проверен ZIP, скачанный через интерфейс опубликованной сборки.

27/27 основных и 11/11 редакторских тестов проходят. Живой Chromium проверил открытие Пильны, миграцию старого автосохранения, восстановление карты 2048 после перезагрузки, изоляцию браузерных сессий, выбор полных поисковых границ, сохранение, повторное открытие и скачивание мода. Общий цикл редактирования и отмена задержанного импорта также проходят; браузерных ошибок не было.

Свежий независимый reviewer нашёл большие расходы истории, лимит localStorage и принятие старого сервера. Все три замечания исправлены одним проходом. История использует страничные byte-дельты с бюджетом 64 МБ; автосохранение хранится в рабочей папке; launcher проверяет версию 0.2. На полном поле 2048 заливка с записью истории заняла 128 мс в отдельном Node-прогоне; undo/redo побитно восстанавливают слой. После 12 смен поверхности история удерживает 56 МБ / 7 действий и соблюдает бюджет. Это замер модели, а не кадровой частоты интерфейса. Launcher проверен с `-NoBrowser`.

Прохождение в игре, реальный лут, крыши и мультиплеер остаются непроверенными. Изометрический обзор схематический. Железнодорожный слой пока не переносится. ZIP воспроизводим по содержимому при одном источнике/рецепте, но даты записей отличаются между сборками.
